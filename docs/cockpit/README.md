# Nafura Labs — cockpit

**Nafura Labs** = projet master. Tout le reste = sous-projets.

Deux fichiers seulement :

| Fichier | Rôle |
|---------|------|
| [active-week.md](active-week.md) | Semaine en cours — ordonné par priorité, par projet |
| [backlog.md](backlog.md) | File d’attente — ordonné par priorité, par projet |

## Règles

1. Lire `active-week.md` avant de proposer du travail.
2. Hors active-week → proposer d’ajouter au `backlog.md`, pas d’exécuter.
3. Fin de semaine : cocher / déplacer active → done ou retour backlog.
