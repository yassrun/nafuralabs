# nf-screen — cadre d’écran platform

> Une route métier = un écran. Listing, fiche, dashboard et special **remplissent** le body. Ils n’inventent pas le chrome.

**Pact :** anatomy dans `nafura-platform/sources/web/lib/anatomy`. Pas un lot Sektor. Pas un BC.

**Actif :** sous-lot [`cadre-v1/`](cadre-v1/) — header + breadcrumbs + body. Adoption Sektor : **catalogue, études, achats, ventes, chantiers**.

Homogénéisation Sektor (actions / filtres) reste [`sektor/raster-src/lots/homogenisation-ux/`](../../../../sektor/raster-src/lots/homogenisation-ux/) : elle consomme ce cadre, elle ne le redéfinit pas.

## Hors lot

- Dossier étude, budget, saisie avancement, magasin, scanner, guest
- RH / finance / HSE / marchés / socle
- Slot actions / tabs / footer d’écran
- Bouton retour (`AC-1` homogenisation) dans le header
- Create listing dans le header
